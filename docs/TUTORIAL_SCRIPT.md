# Сценарий обучения

Единственный источник правды по текстам первых пяти уровней. Мобильное
приложение читает их из `lib/data/tutorial_script.dart`, веб — из
`src/game/tutorialScript.ts`; **строки обязаны совпадать**, иначе игроки на
двух платформах учатся по разным правилам.

Это уже случалось: обе копии писались вручную, тестов не было, и в обеих
жила одна и та же грамматическая ошибка — имя фигуры хранилось в винительном
падеже и подставлялось в три разные позиции, отчего игра говорила
«Начните с ладью» и «ладью уже ждёт вас в панели».

Поэтому таблица ниже проверяется тестами в обоих проектах:

- мобайл — `test/tutorial_script_test.dart`
- веб — `src/tests/tutorialScript.test.ts`

Тест падает, если строка в коде отличается от строки здесь хотя бы одним
символом. **Меняя текст, правь таблицу в обоих репозиториях одним коммитом.**

## Правила формулировок

- **Сначала глагол.** Игрок читает подсказку, чтобы понять, что делать;
  объяснение лучше ложится после действия.
- **Одна мысль — одна карточка.** Самая длинная реплика была 118 символов и
  читалась как абзац.
- **Одно слово на одну вещь:** монета, фигура, луч, светящаяся клетка. Раньше
  те же пять вещей назывались ещё и «пунктирная линия», «линии», «номинал»,
  «число ударов», «подсвеченная клетка».
- **Имена фигур только в именительном падеже.** Предложения построены так,
  чтобы `{piece}` всегда вставал в именительном — это и есть защита от
  падежных ошибок.

## Строки

| Идентификатор | Текст |
| --- | --- |
| `l1.place` | Перетащите пешку на светящуюся клетку. |
| `l1.ray` | Луч дошёл до монеты: пешка бьёт по диагонали вперёд. |
| `l2.place.first` | {piece} — на светящуюся клетку. Или тапом: фигура, клетка. |
| `l2.place.second` | Теперь {piece} — на вторую светящуюся клетку. |
| `l2.ray` | Ладья бьёт по прямым, слон — по диагоналям. |
| `l3.place.first` | Цифра на монете — сколько лучей ей нужно. |
| `l3.place.second` | Теперь {piece} — на вторую светящуюся клетку. |
| `l3.ray` | Проверьте: лучей ровно столько, сколько на монете. |
| `l4.hint` | Не знаете куда? Нажмите лампочку — покажем клетку. |
| `l4.place.king` | Король — на светящуюся клетку: он бьёт вокруг себя. |
| `l4.place.first` | {piece} — на светящуюся клетку. |
| `l4.place.next` | Дальше {piece} — на светящуюся клетку. |
| `l4.ray` | Лучей у монеты должно быть ровно столько, сколько на ней. |
| `l5.trial.first` | Попробуем так: {piece} — на светящуюся клетку. |
| `l5.trial.second` | Теперь {piece} — на светящуюся клетку. |
| `l5.overflow` | Лучей больше, чем нужно. Нажмите сброс — попробуем иначе. |
| `l5.place.first` | {piece} — на светящуюся клетку. |
| `l5.place.second` | Теперь {piece} — на вторую светящуюся клетку. |
| `l5.ray` | Две фигуры вместе должны зажечь все три монеты. |

`{piece}` подставляется в именительном падеже; если фигура почему-то
неизвестна, вместо неё встаёт «Фигура» — во всех предложениях выше это
читается корректно.

## Когда какая строка

| Состояние | Строка |
| --- | --- |
| Уровень 1, фигура ещё в лотке | `l1.place` |
| Уровень 1, фигура поставлена | `l1.ray` |
| Уровни 2–3, доска пуста | `l2.place.first` / `l3.place.first` |
| Уровни 2–3, одна фигура стоит | `l2.place.second` / `l3.place.second` |
| Уровень 4, до первой подсказки | `l4.hint` |
| Уровень 4, очередь короля | `l4.place.king` |
| Уровень 5, первая попытка | `l5.trial.first` / `l5.trial.second` |
| Уровень 5, монета перебрана | `l5.overflow` |
| Уровень 5, после сброса | `l5.place.first` / `l5.place.second` |
| Любой уровень, лоток пуст | `l*.ray` |

Карточка остаётся на экране и после решения уровня: именно в этот момент
объяснение про луч попадает в цель, потому что луч только что появился.
Инструкций она там не даёт — раньше говорила «нажмите «ГОТОВО»» над кнопкой
«ПРОДОЛЖИТЬ».
